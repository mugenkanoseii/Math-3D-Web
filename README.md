# Math 3D Web

Web dạy Toán học có trực quan hóa 3D tương tác.

## 🧭 Team & Quy trình làm việc

Dự án được xây dựng bởi 1 đội hình gồm nhiều vai trò chuyên môn (Leader, Frontend, 3D Specialist,
Math Curriculum Designer, UX/UI Designer, Backend, QA, DevOps). Chi tiết vai trò, phân công, và
quy tắc làm việc xem tại tài liệu **Team Charter** (lưu ở Google Drive dùng chung của team).

## 🔒 Quy tắc bắt buộc khi đóng góp code

1. **Không push trực tiếp vào `main`** — mọi thay đổi phải qua nhánh riêng + Pull Request.
2. **Đặt tên nhánh theo format:** `feature/<ten-tinh-nang>` (VD: `feature/3d-vector-scene`).
3. **Không tự ý thêm/bớt giao diện hay tính năng ngoài phạm vi task được giao.**
4. **Không sửa các phần đã "ĐÃ CHỐT"** (được đánh dấu trong Team Charter) trừ khi task yêu cầu rõ ràng.
5. **Commit message rõ ràng**, mô tả đúng thay đổi để dễ review diff.
6. **Không commit bất kỳ secret nào** (API key, mật khẩu, token, file `.env`...) — repo này là public.

## 📁 Cấu trúc dự án

Cấu trúc thư mục cụ thể (frontend/backend/assets...) sẽ được cập nhật khi tech stack được chốt.
